【快速启动方式】
1. Windows 用户（推荐）：
   - 直接解压此压缩包到任意文件夹（如桌面或常用盘）。
   - 双击文件夹内的「双击启动.bat」或「Start_Windows.bat」即可！
   - 系统将自动打开默认浏览器访问应用（http://localhost:5273）。
   - 绝大多数 Windows 10 / 11 电脑均无需安装任何开发工具或 Node.js 环境（内置纯净 PowerShell 引擎支持）。

2. macOS / Linux 用户：
   - 在终端中打开此目录，运行：bash "启动_Mac_Linux.sh"
   - 或进入 dist 目录使用任意静态服务器打开 index.html。

3. 退出方法：
   - 直接关闭运行中的黑框控制台窗口，或在控制台中按下 Ctrl + C 即可退出。

【软件特色功能】
1. 自适应学习与水平诊断：支持 N0 零基础、N5、N4、N3、N2、N1 各级别阶梯式教学。
2. 双语阶梯密度引导：低级别以清晰易懂的中文讲解为主，高级别自然过渡到沉浸式日语交流。
3. 沉浸式振假名与声调显示：教材级日文汉字振假名注音，支持平假名注音与高低声调标注。
4. 智能学情档案与词典系统：
   - 点击正文中的日语词汇即可呼出智能词典，提供详细释义与例句，自动节约 Token；
   - 支持“初学”、“温习”、“已掌握”三阶段学情流转与闪卡自测；
   - 手动使用 AI 精释可直接同步更新并覆盖离线词库与生词本；
   - 跨会话先验记忆：AI 牢记所有已学词汇，绝不重复当成生词科普。
5. 角色与人设深度定制：
   - 支持自定义私教名字（默认 Shiori AI）、人设风格、第一人称自称与对学生称呼；
   - 社交软件级圆形头像上传，内置方便的拖拽/滚轮缩放/90度旋转裁剪工具；
   - 支持预设库自由切换（如温婉知性学姐薫子、元气同伴阳葵、严谨学者佐藤教授等），并支持一键导出/导入自定义预设。
6. 多模型支持：预设集成 Gemini、DeepSeek、OpenAI、月之暗面 Kimi、通义千问 Qwen、硅基流动等主流大模型。
